# 技术说明

## 结构

```text
dist/
  index.html              页面结构、对话框、SEO 元信息
  style.css               主场景样式与响应式布局
  app.js                  漂浮水瓶、涨水、原话与梗、收藏、声音
  features.css            饮水记录与测试界面
  features.js             饮水记录、日期处理、测试计分和本地存储
  polish.css              质感与细节调整
  assets/
    hero-dashui.webp       AI 二创人物与马赛克
    bottle-dashui.webp     虚构大水瓶
    drop.svg              水滴图标
  robots.txt
  sitemap.xml
```

`dist/` 已经是完整可运行页面，不是等待编译的中间文件。没有 `node_modules`、构建服务、前端框架或外部 CDN。新增仓库中的说明文档不参与网站运行。

## 本地预览

如果已安装 Python 3，从仓库根目录运行：

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:8080/`。其他静态文件服务器也可使用。直接打开 HTML 文件与通过 HTTP 预览时，存储源和剪贴板能力可能不同，因此建议通过本地服务器查看。

## 状态与存储

- 收藏、饮水记录、测试结果使用当前浏览器的 `localStorage`。
- 饮水按 `Asia/Shanghai` 计算日期，饮水量单位为 mL，界面校验输入范围。
- 题目按三组维度累加并换算为娱乐分数；题目与算法可直接在 `features.js` 阅读。
- 浏览器清除站点数据、隐私模式或更换设备都可能使已有记录不可用。
- 没有登录、数据库、支付、分析埋点或应用侧上传接口。托管平台的网络日志不在应用代码控制范围内。

## 静态部署的实际要求

项目使用相对静态资源路径，但 canonical、Open Graph 图片地址、JSON-LD、robots 和 sitemap 中有正式域名。这里保留作者正式站点的地址。

作者维护自己的部署时，应将 `dist/` 内容作为网站根目录发布；域名需要按托管服务要求配置 DNS，HTTPS 需要证书。域名注册、站点发布、域名解析、证书配置、搜索收录是分开的步骤。

第三方若希望修改或另行部署，请先取得作者许可；技术说明本身不授予修改许可。

## 验证方法

公开发布前检查静态文件的完整性、JavaScript 语法、相对资源引用，以及公开目录是否含有凭证或个人信息。域名和网络验证记录见 [PROCESS.md](PROCESS.md)。本仓库不以一个 HTTP 200 结果声称全球访问可用，也不把娱乐测试当作科学验证结果。
