# 素材、来源与隐私说明

## 人与 AI 的协作

用户提出主题、参考、玩法、成本和发布约束，并在迭代中做取舍；AI 助手协助实现前端、整理文案与来源、生成视觉素材、排查部署和整理文档。这里的“我们的思考”是依据对话整理的公开项目决策，不是私人聊天逐字公开，也不是对真人未公开观点的推断。

## 视觉素材

`hero-dashui.webp` 与 `bottle-dashui.webp` 是本项目制作的 AI 生成视觉素材，人物采用整脸马赛克，瓶子采用虚构“大水”标签。`drop.svg` 是简单水滴图形。

用户提供的原始参考照片、品牌包装截图和域名管理截图没有随仓库公开。页面不使用真实品牌商标，也不宣称得到真人、品牌或报道机构的授权或代言。

AI 生成、遮挡脸部或更换标签并不自动排除人物形象、商标及其他第三方权利。仓库的权利保留说明仅适用于发布者有权控制的部分，不把第三方内容或所有 AI 输出笼统声明为独占版权。

## 文字来源

带“孙哥原话”标记的内容来自公开采访或报道的短句节选。链接与语境见 [SOURCES.md](../SOURCES.md)；相关报道、原话、翻译等第三方权利仍归相应权利人。

其他梗句和测试题为本项目编写的文案，不归因于孙宇晨本人。部分玩梗借用了常见网络或广告句式，“原创玩梗”是网页的内容分类，不表示每一种句式都前所未有或不存在第三方权利。网站不提供投资建议、健康处方或心理诊断。

## 应用侧数据

网页在当前浏览器本地保存收藏、饮水记录和测试结果；本项目代码没有把这些记录上传到应用服务器的接口。仓库不包含任何真实用户记录。

“本地保存”不等于网络访问没有日志。网站托管服务和 DNS 等基础设施可能按各自规则处理 IP、请求时间等常规技术信息，GitHub 的访问和 Fork 行为也受其平台规则约束。

- 原部署仓库的 `.git/` 历史、远程配置和作者本机路径。
- `.openai/` 等绑定既有云项目的配置。
- API 密钥、临时令牌、证书私钥与账号凭据。
- DNS 所有权与证书验证值、内部项目编号。
- 控制台截图、二维码、账号资料、支付页面及安全日志。
