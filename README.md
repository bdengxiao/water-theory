# 大水理论 · Water Theory

**世界太抽象，先喝一口水。**

一个由人与 AI 一起完成的非官方互动玩梗网页：漂浮水瓶、公开原话、原创梗句、每日喝水记录，以及一份只供娱乐的“大水思维”测试。

## 可以玩什么

- 点击或拖动漂浮的“大水”水瓶，收集文案。
- 在“都来点 / 孙哥原话 / 原创玩梗”之间切换。4 条原话节选保留报道出处，24 条原创梗句单独标识。
- 按住按钮或空格键召唤大水，松开后水位退去；可暂停、重置和选择开启声音。
- 记录每日实际饮水量，支持补记、撤销、删除、自定目标和最近 7 天展示。
- 完成 6 道原创娱乐题，查看消费取舍、小步执行、独立判断三个维度的结果。

首屏“大水值”是视觉玩梗数值，与真正喝了多少水无关。测试不判断人格、财富或健康，也不是孙宇晨本人提出或设计的测评。

## 本地查看

正式网页文件全部在 `dist/`，无需 npm 安装或构建。如果已安装 Python 3，可在仓库根目录运行：

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

然后访问 `http://127.0.0.1:8080/`。其他静态文件服务器也可以。仅在本地运行未修改的副本进行查看；其他用途请先取得作者许可。

## 技术与数据

原生 HTML、CSS、JavaScript，无外部字体、第三方脚本或运行时 CDN 依赖。收藏、喝水记录、测试结果保存在当前浏览器 `localStorage`，没有账户系统和应用数据库，不跨设备同步。托管平台仍可能处理常规访问日志，参见[隐私边界](docs/PROVENANCE.md)。
